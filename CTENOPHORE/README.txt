CTENOPHORE — THE LIVING PRISM
Interactive 3D ASCII bioluminescent comb jelly — Kobsi, 2026

A translucent lobate comb jelly you can pilot directly through deep abyssal
water. Eight beating comb rows diffract cyan, teal, violet, and pearl light
while two lacy tentacles and 460 bioluminescent plankton react to your swimming
and cursor currents.

Run from the repository root:
  pip install -r CTENOPHORE/requirements.txt
  python CTENOPHORE/ctenophore.py

Controls:
  W/S or Up/Down     Swim forward / reverse
  A/D or Left/Right  Steer left / right
  Q/E                Dive / ascend
  Shift              Bioluminescent jet-surge
  Space              Trigger prism pulse & chime
  C                  Toggle follow-cursor autopilot
  Left-click         Drop 3D sonar ripple
  Left-drag          Stir water currents & gather plankton
  Right-drag         Orbit 3D camera
  1 / 2 / 3          Sea state (Abyssal Calm / Prismatic Bloom / Midnight Surge)
  P                  Pause
  R                  Reset
  S                  Screenshot
  F                  Fullscreen
  M                  Mute audio
  Esc                Quit
